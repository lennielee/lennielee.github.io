# Linze Li's Homepage

Source of https://lennielee.github.io, built with [PRISM](https://github.com/xyjoey/PRISM) (Next.js + Tailwind CSS).

- Edit content in `content/` (`config.toml`, `bio.md`, `cv.md`, `awards.toml`, `teaching.toml`, `services.toml`, `publications.bib`).
- Local preview: `npm install && npm run dev`, then open http://localhost:3000.
- Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
